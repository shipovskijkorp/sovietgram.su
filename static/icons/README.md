# Telegram Desktop icon source

The icon shapes in `telegram.svg` are derived from Telegram Desktop 7.2.9
resources, primarily `Telegram/Resources/icons/menu/`, and are adapted as a
single monochrome sprite so Stalingram can recolor them with its own palette.

Telegram Desktop is distributed under the GNU General Public License version 3
with its documented OpenSSL exception. See the upstream Telegram Desktop
repository and license for the applicable terms.

No Telegram color palette, branding, or logo is used by this sprite.
